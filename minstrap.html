Minimal CSS grid layout system inspired by Bootstrap

The layout below the default layout. An ms-container with max-width at each responsive breakpoint. Inside it is a ms-container with three ms-column of equal sizes and left/right gutters.
For illustration, each row has a green border, and each column has light blue background showing its content box.

col 1 col 2 col 3

There are 12 template columns per row. For each column, we can specify how may template columns it spans by adding a span-{num} from span-1 to span-12.
Below, we have 3 columns with span-4, span-6 and span-2 classes

4 6 2

The span-* classes by default work across all the responsive breakpoints from xs to xxl.
When we want override the number of template columns to span per responsive breakpoint we can use the sm-* to xxl-* classes.
In the first row below, each column has the following classes span-12 sm-6 md-4 lg-3 xl-2 and will set the appropriate span size at each breakpoint.
We can specify the span-auto class to make a column fit its content, as seen in the second row.
